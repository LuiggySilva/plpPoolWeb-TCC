Revisão de Importação

Analise as questões identificadas durante a importação e escolha quais devem ser adicionadas ao banco de dados.

A verificação de similaridade compara automaticamente a nova questão com as já existentes no banco de dados utilizando:
  • Enunciado
  • Descrição
  • Código
Quando qualquer um desses campos atingir uma similaridade superior a 75% e ambas serem na mesma linguagem, a questão será sinalizada para revisão manual antes da importação.
